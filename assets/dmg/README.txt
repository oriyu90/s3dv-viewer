S3DV viewer — インストールと初回起動について
==========================================

S3DV viewer は、S3DV 形式の録画データ（3D 点群のストリーム）を macOS 上で
再生・確認するための研究用ビューアです。


インストール
------------
1. このディスクイメージのウインドウで「S3DV viewer.app」を
   「Applications」フォルダへドラッグします。
2. コピーが終わったら、このディスクイメージを右クリック →
   「"S3DV viewer" を取り出す」で取り出してください。
3. Applications フォルダから S3DV viewer を起動します。


初回起動時の警告（Gatekeeper）について
--------------------------------------
このアプリは研究用キットのため、アドホック署名のみで配布しています。
Apple の Developer ID 署名と公証（notarization）は行っていません。
そのため初回起動時に「開発元を確認できないため開けません」などの警告が
表示されます。次のいずれかの方法で起動してください。

  方法 A: 右クリックして「開く」
    1. Applications フォルダで S3DV viewer.app を Control キーを押しながら
       クリック（または右クリック）します。
    2. 表示されたメニューから「開く」を選びます。
    3. 確認ダイアログでもう一度「開く」をクリックします。
    2 回目以降は通常どおりダブルクリックで起動できます。

  方法 B: 隔離属性（quarantine）を外す
    ターミナルで次を実行します。

        xattr -dr com.apple.quarantine "/Applications/S3DV viewer.app"

    実行後はダブルクリックで起動できます。このコマンドは、ダウンロード時に
    付与される「隔離」属性をこのアプリについてだけ解除します。

  補足: システム設定 > プライバシーとセキュリティ の「このまま開く」からも
  起動できますが、上記 A / B のどちらかを推奨します。


動作環境
--------
- macOS 13 以降
- 本ビルドは arm64（Apple Silicon）向けです。
- 初回起動時にネットワーク接続は不要です（three.js は同梱）。


不具合の報告
------------
不具合や要望は、研究室内の S3DV リポジトリ（S3DV_研究）の Issue、または
配布担当者までご連絡ください。あわせて次の情報があると助かります。

- 再現手順
- macOS のバージョン（例: 15.3）
- 可能であれば コンソール.app の該当ログ
